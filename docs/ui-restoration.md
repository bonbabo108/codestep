## 意図的に旧実装へ戻さない部分

- 旧学習画面は固定3問で、クリア済と復元案内を常に表示していた。固定問題へ戻さず、**実際に保存/復元された場合だけ**元のデザインで表示する。匿名の正解は保存しないが、不要な未ログイン説明は常設しない。
- 元の管理リンクは全利用者に表示されていた。現在は有効なセッションのapp_metadata.codestep_adminがboolean trueの場合だけ表示する。直接URLは現在の管理者ガード、API操作は既存RLSで制限する。本番の管理者付与は行わない。
- セッション初期確認/ログアウト通信中は元のLoading...表示を使い、ログアウト完了前にログインリンクを出さない。通信失敗時のエラーを隠さない。通常の権限再取得は再ログイン/自動更新、管理権限付与後の手動更新は専用拒否画面から利用できる。古いJWTの権限残存という既存の制約は変わらない。
- スマホはヘッダーの行全体を折り返し、長いユーザー呼称を省略して崩れを防ぐ。元の狭幅表示でリンクやログアウトの文字が細切れになる状態まで再現しない。
- 正誤判定は現在の前後空白を除く大小文字を区別した一致を維持。元のtoLowerCaseによる判定には戻さない。コードは実行しない。
- 保存中/保存成功/保存失敗、0件更新/削除、FK拒否、通信結果不明の案内と二重送信防止は維持する。専用再読み込みボタンを廃止したため、取得エラー/最新一覧の再取得はブラウザ標準の再読み込みを使う。
